Privacy policy

For the "JT Capital Shorts" app and this website. Effective 28 September 2026.

Who we are

JT Capital Shorts is a private tool operated by Haifeng (JT) Tan. Its only purpose is to upload JT's own approved videos to his own YouTube channel, JT Capital. Contact: haifeng.tan@gmail.com.

What Google data the app accesses

The app requests one permission from the channel owner's Google account: https://www.googleapis.com/auth/youtube.upload ("Manage your YouTube videos"). It uses this permission only to upload a video, set its title, description, tags and privacy status, and schedule its publish time on the JT Capital channel.

The app does not read, collect or store data about any other person. It does not access viewers' data, comments, subscribers, analytics, email, contacts or any other Google service.

How the data is stored and protected

The sign-in token that Google issues to the app is stored on a private server, in a file readable only by the owner's account. It is used only by the upload tool. It is never sold, shared, transferred to third parties, or used for advertising.

Limited Use

JT Capital Shorts' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

The account owner can revoke the app's access at any time at myaccount.google.com/permissions. When access is revoked or the tool is retired, the stored token is deleted from the server. To ask about or request deletion of any data, email haifeng.tan@gmail.com.

This website

This site is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics or tracking. GitHub may keep standard server logs, as described in the GitHub Privacy Statement.

Changes

If this policy changes, the updated version and its effective date will be posted on this page.
